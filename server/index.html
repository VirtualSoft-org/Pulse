🚀 WebRTC P2P Demo

Real-time peer-to-peer communication using Supabase Realtime signaling

🎙️ Host (Left)
💬 Client (Right)

How to Use

  1. Click Connect & Start on the Host (left panel)
  2. Click Connect to Host on the Client (right panel)
  3. Wait for both to show 🟢 status
  4. Type a message in either panel and click Send
  5. Messages appear in real-time on the other side

This demo uses Supabase Realtime for WebRTC signaling (offer/answer/ICE candidates) and browser WebRTC DataChannels for P2P messaging.
